## 📌 Ringkasan Eksekutif (Executive Summary)

**CodeSync 2026** adalah proyek pengabdian masyarakat dan inkubasi teknologi terapan yang diinisiasi oleh 17 mahasiswa Program Studi Informatika President University (IT Class 5, Group 1) Cikarang, Bekasi. Berkolaborasi secara resmi dengan **SMK Negeri 40 Jakarta**, proyek ini bertujuan untuk merevolusi paradigma pembelajaran siswa Rekayasa Perangkat Lunak (RPL) dari pembuat kode pasif (*monolithic CRUD developers*) menjadi perancang solusi kecerdasan buatan otonom (*Agentic AI System Architects*).

Melalui integrasi pendekatan **Community-Based Participatory Approach (CBPA)**, **Capacity Building**, dan **Teaching Factory (TeFa)**, CodeSync 2026 menempatkan sekolah mitra sebagai klien dunia nyata. Siswa membimbing diri mereka untuk mengidentifikasi *bottleneck* operasional sekolah dan membangun solusi *AI-Powered System* yang fungsional, siap pakai, dan berdampak langsung secara gratis.

---

## 🚀 Masalah & Solusi (Problem & Solution)

### 1. Kesenjangan Kompetensi Industri vs Kurikulum SMK
* **Masalah:** Kurikulum pemrograman kejuruan konvensional cenderung terbatas pada aplikasi CRUD (*Create, Read, Update, Delete*) statis. Sementara industri modern telah bertransformasi ke ekosistem *Agentic AI* dan *Large Language Models* (LLMs).
* **Solusi CodeSync:** Pembekalan arsitektur *Agentic AI Infrastructure* dan pendelegasian instruksi terstruktur menggunakan framework **CTCF** (*Context, Task, Constraints, Format*).

### 2. Hambatan Psikologis & Kesiapan PKL
* **Masalah:** Kurangnya pengalaman menangani klien riil memicu kecemasan kompetensi (*readiness gap*) saat siswa memasuki Praktik Kerja Lapangan (PKL).
* **Solusi CodeSync:** Simulasi lingkungan kerja *Agile/Scrum* dan *Co-Development Sprint* bernuansa *hackathon* di mana mahasiswa bertindak sebagai *Tech Lead* mendampingi siswa (rasio 1:2).

### 3. Inefisiensi Operasional Sekolah Mitra
* **Masalah:** Rekapitulasi presensi manual, penataan inventaris, dan penanganan pertanyaan berulang orang tua murid memakan energi operasional sekolah.
* **Solusi CodeSync:** Prototipe *AI-Powered Systems* buatan siswa yang diserahkan dan di-deploy secara lokal untuk mengotomatisasi proses administratif sekolah.

## 🏗️ Framework & Metodologi

### Framework Rekayasa Prompt CTCF
Untuk memastikan *AI Agent* menghasilkan luaran yang akurat, deterministik, dan aman, seluruh sistem yang dikembangkan wajib menerapkan struktur **CTCF**:

```
+-----------------------------------------------------------------------+
|  C - Context      : Definisi peran AI, domain masalah, & profil user |
|  T - Task         : Instruksi spesifik & alur kerja otonom            |
|  C - Constraints  : Batasan operasional, keamanan data, & guardrails  |
|  F - Format       : Struktur luaran (JSON, Markdown, Table, REST API) |
+-----------------------------------------------------------------------+
```

### Skema Teaching Factory (TeFa) & Mentorship
```
[ Sekolah / Klien ] ---> (Problem Discovery) ---> [ Siswa RPL (Developers) ]
                                                          ^
                                                          | (Mentorship 1:2)
                                                          v
                                               [ Mahasiswa (Tech Leads) ]
```

## 🗓️ 4 Fase Eksekusi Program

1. **Fase 1: MasterClass "Agentic AI Infrastructure"**
   * Seminar umum literasi digital untuk ±200 siswa lintas jurusan.
   * Pelatihan mendalam framework CTCF & arsitektur *AI Agent* untuk ±36 siswa RPL Kelas 11.
2. **Fase 2: Problem Discovery**
   * Sesi wawancara langsung di mana guru & staf administrasi SMKN 40 Jakarta bertindak sebagai klien nyata.
   * Analisis kebutuhan sistem (*requirements gathering*) & penyusunan backlog.
3. **Fase 3: Co-Development Sprint (Hackathon)**
   * *Agile Sprint* intensif perancangan basis data, integrasi LLM API, dan logika aplikasi.
   * Pendampingan langsung oleh 17 *Tech Lead* mahasiswa President University.
4. **Fase 4: Capstone Pitching & Deployment**
   * Presentasi prototipe di hadapan panel juri industri & jajaran sekolah.
   * Penyerahan produk fungsional kepada sekolah & penerbitan *e-certificate* terverifikasi Blockchain.

## 🛠️ Stack Teknologi & Infrastruktur

* **AI & LLM Integration:** OpenAI GPT-4o / Claude API / Local Ollama, LangChain / LlamaIndex framework.
* **Prompt Engineering:** CTCF Framework Standard.
* **Frontend/Backend:** Next.js, Python (FastAPI/Flask), Node.js, TailwindCSS.
* **Database & Storage:** PostgreSQL / Supabase, SQLite, VectorDB (Chroma/FAISS).
* **Credentialing:** Blockchain-verified E-Certificates.
* **Infrastructure Pool:** Managed LLM Token Pool (Budgeting & Rate Limiting).
